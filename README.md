# Cashstead demo

Static uncertain-income planning demo. No bank connections, accounts or server-side financial storage. Entered plans stay in browser localStorage (unencrypted). Export backups before clearing browser data. Hosting may log IP addresses.

Demo estimates only, not financial advice or a guarantee. Cashstead is an uncleared working name.

Version 0.3: stress-test one expected payment or all of them; result-first mobile scenarios. Includes dated weekly/monthly entries and local backups.
